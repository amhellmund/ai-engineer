# AI Engineering Fundamentals

📖 **Read it online: <https://amhellmund.github.io/ai-engineer/>**

> Become an AI engineer with solid, hands-on knowledge — one 30-minute tutorial a day.

## The idea

There's no shortage of AI tutorials, but most jump straight to calling an API or
gloss over *why* things work. This project takes the opposite approach: build a
**solid foundation** that goes all the way from the base components of modern AI up
to running models and agents in production.

You start by understanding the building blocks — PyTorch, embeddings, transformers,
training loops — and progressively work up to fine-tuning, alignment, evaluation,
retrieval, agents, and LLMOps. Every topic is a short, self-contained, hands-on
tutorial you can finish in about **30 minutes a day**.

## What you'll learn

By the end you'll be able to:

- Understand transformers from the inside out — self-attention, RoPE, GQA, KV caching
- Build and train a small language model from scratch
- Fine-tune open models with modern pipelines (LoRA/QLoRA, Axolotl, Unsloth)
- Curate and generate training data, and align models with DPO/ORPO/SimPO
- Evaluate models rigorously (lm-eval-harness, LLM-as-judge) and track experiments
- Quantize, serve, and merge models (GPTQ/AWQ/GGUF, vLLM, mergekit)
- Build RAG systems and AI agents
- Deploy, monitor, and secure LLM applications in production

## Format

- **120 tutorials**, one per day, ~30 minutes each
- Grouped into **24 sections of 5 tutorials**
- Ordered so each topic builds on the last — foundations first, no hand-waving

The learning arc:

**Foundations** → **Transformers & internals** → **Using LLMs** →
**Fine-tuning track** → **Applications (RAG & agents)** → **Production & capstone**

## Who it's for

Developers and ML practitioners who want to go beyond surface-level API usage and
genuinely understand how modern AI systems work — and how to build, adapt, and ship
them. Comfort with Python is assumed; the necessary math and deep-learning
fundamentals are covered along the way.
